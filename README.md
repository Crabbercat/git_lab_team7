Repository thực hành Git và GitHub của Team 7.

Dự án được sử dụng để thực hành quy trình phát triển phần mềm cộng tác trên GitHub, bao gồm Git Flow, GitHub Flow, Pull Request, Code Review, Conflict Resolution và các công cụ hỗ trợ dự án mã nguồn mở.

---

## Mục tiêu

Repository này được xây dựng nhằm thực hành:

- Quản lý source code bằng Git.
- Làm việc với repository trên GitHub.
- Branching và merging.
- Git Flow và GitHub Flow.
- Pull Request và Code Review.
- Xử lý merge conflict.
- Git Stash.
- Issue và Issue Template.
- Pull Request Template.
- Branch Protection.
- Contributor workflow.
- Community Health Files.

---

## Git Workflow

Quy trình làm việc cơ bản của nhóm:

```text
Issue
  ↓
Create Branch
  ↓
Develop
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Code Review
  ↓
Resolve Feedback / Conflict
  ↓
Merge
  ↓
Delete Branch
